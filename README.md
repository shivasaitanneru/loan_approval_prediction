# Loan Approval Prediction

Machine Learning project for predicting loan approval using applicant information.

## Project Overview

This project applies supervised machine learning techniques to predict whether a loan application will be approved.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Gaussian Naive Bayes

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Feature Encoding
6. Feature Engineering
7. Train-Test Split
8. Model Training
9. Model Evaluation
